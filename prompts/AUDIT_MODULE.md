# MODULE AUDIT

Audit the requested module without coding.

Trace routes, controllers, models, helpers/services, SQL, tables, views, imports, validation, business rules, external integrations, and side effects.

Classify every important finding:
VERIFIED / INFERENCE / UNKNOWN

Produce:
1. current flow
2. dependency map
3. database mapping
4. business rules
5. risks
6. unknowns
7. recommended V2 boundary

Stop after the audit.
